# prsnn

Book verified companions for platonic company, in public places. One repository for the whole product:

| Folder | What | Runs on |
|---|---|---|
| `mobile/` | The iPhone and Android app (Expo, React Native, TypeScript) | App Store, Google Play (EAS builds) |
| `backend/` | Database migrations, tests and edge functions | Supabase project `mhovyhapzhxcmcuelbol` |
| `web/` | prsnn.com (Next.js static site) | Cloudflare (build folder `web/`) |

Each folder keeps its own README, CLAUDE.md and history (imported 18 Nov 2026 from `prsnn-mobile`, `prsnn-backend` and
`prsnn-frontend`, which are now archives). Start with `mobile/docs/RELEASE-2026-11-18.md` and `mobile/docs/LAUNCH_GUIDE.md`.
